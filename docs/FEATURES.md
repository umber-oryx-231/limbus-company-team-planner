# Limbus Company Team Planner — feature reference

Limbus Company Team Planner brings team profiles and character notes into one section-based interface. Encounter records provides the third part of the workflow.

| Section | Description |
|---|---|
| Team profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Character notes | Character-related parameters and the settings associated with the selected category. |
| Encounter records | A dedicated section for encounter records and the configuration details associated with that area. |

The project page follows the same section structure.
